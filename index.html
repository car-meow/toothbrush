Patch Notes
4.0 is here! This update is a big one, and I can't wait for y'all to check it out. Let's do a quick overview. The Stash has been completely localized, meaning that old deprecated system is now only a fallback (you can enable it in settings if some games don't work, I'm still bugfixing). The Stash is now a lot more user-friendly, and the Games Tab has been updated to be more responsive and smooth. So has every single facet of this site; in fact, the amount of optimizations I had to make probably totals to ~150 hours. It should be a lot smoother now on those crappy Chromebooks (also known as E-waste). Some settings have been enabled by default, and a few new ones have been added to help with performance. If you have a low-end device, I highly recommend enabling Performance Mode in the Settings menu. It will make a world of difference. Also, settings have been removed to make it more user-friendly. Light Mode has been fully fleshed out with new backgrounds, and a more unified font. The Stash has been updated as the font is now unified, saving and loading got a major revamp since you can now choose individually what games you want to save and load, and there's a (not fully done) saving manager where you can delete save files for specific games. I fixed tons of bugs, and when I say TONS, I mean it. Here's some of them, categorized from HUGE to SMALL but still impactful! MAJOR: White-screen bug and loading bug is FINALLY fixed after over 4 months! Now all the games in the Stash should work perfectly, especially Unity games. Saving used to only work if the Nexus tab was open, now it works regardless of if it's open or just the game! Autosaving is also super reliable now. I expanded the backup and restore system to save entire libraries of games, not just saves, including color, save data, and order of all the games. Added general loading and response improvements by reducing redundant prefetching and background work. Also greatly increased performance gain when Performance Mode is turned on. Movies and TV stuff not loading. Search functionality is pretty much instant now. Added Vus Unblocked Tools, a one stop shop (not made by me) which has an insane amount of stuff. Located in the Game Stash, go check it out! NEW: Feature where you cannot open more than one game at a time so computer resources are used less, and so... more performance! The cool part is that when the tab is in the background, it uses less RAM than a literal new tab. (New tab uses 100mb, Nexus uses 55-75mb!) MEDIUM: Rolled out some potential fixes for Mr. Mine game, which couldn't load well for some devices. If it still doesn't work, please report in the Requests/Concerns form. Fixed some games getting stuck on "Adding..." in the sidebar, and moved the newly added games to the top. Fixed outdated IndexedDB version issues, which caused a rare bug that made adding games fail. Fixed deleted games not being re-addeable in the Stash until you refreshed it. Crossy Road's loading issue has been fixed. Added dev mode. Added online users statistic that can be disabled in Settings. Cloaking fixed for when it was broken, new tab cloak works better now Sidebar games will now never lose their order when you refresh the page, and will always be in the order you set them to. They will also keep their color. Kinda SMALL: Search layouts in the Game Stash were fixed, removing those annoying gaps in Search. New tab favicon added instead of a blank one. Fonts should now read properly on Chromebook, bundling the .ttf files locally instead of relying on Google Fonts. General polish update as per usual. And stuff that's currently IN THE WORKS for 4.0 (coming to Chromebooks near you!): - More games-- they will definitely be more high quality than the current ones-- and more features and UI updates for the Stash, think pictures! - Updated media providers so some issues with media blockage will be solved - AI chatbot not working sometimes due to "server full" issues, will be fixed with a new backend if I can figure it out and definitely less waiting times - More polish and bugfixes, as always, and more performance improvements Aaaaand that's all, folks. 4.0 is here, but that doesn't mean that we're done with Nexus! I'm definitely going to hold off on any more major updates for now, since I need to pass my classes, but if you have any "Requests/Concerns" click that button and fill it out, and I should try and do something about it in a day or two. I'll catch you later, dev OUT!
